## Stygia 2.1.1

Dark theme for phpMyAdmin 6.x — usability polish, One Dark Pro typed cells, and modal/datepicker fixes.

### Highlights
- Underline tabs instead of green CTA pills (pill only on Go/Save)
- Typed browse/insert cells + CodeMirror share the One Dark Pro palette
- Inspectable `--stygia-*` tokens, Inter 300, optional FiraCode Nerd Font
- Login/sidebar lockup: river mark + `phpMyAdmin · STYGIA`
- Modal editors: datepicker, timepicker, dialogs, Bootstrap overlays
- Responsive shell, stronger contrast, orphan legacy PNGs removed
- Full RTL via rtlcss + Stygia overrides

### Install
1. Download `stygia.zip` below
2. Extract into `phpMyAdmin/themes/`
3. Appearance Settings → Theme → **Stygia**
